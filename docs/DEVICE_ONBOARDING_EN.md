# Device onboarding

The maintained PC/central cooperation guide is [Device onboarding with or without existing code](../src/labos/assets/DEVICE_ONBOARDING_EN.md). It is included in the documentation-only onboarding kit and in subsequent full packages built from this source revision.

The proposed runtime migration is documented separately in [Reusable device capabilities and bounded experiment plans](DEVICE_CAPABILITY_EVOLUTION_EN.md). Guidance availability does not mean those proposed runtime capabilities are installed.
