## 关键异常及代码审查

测试覆盖无峰/低对比度、边界峰、多峰、平台峰、非有限与不完整数据、
不合法步长、范围截断、预算不足、缺失批准、错误凭证、下一轮离线、
轮次交界暂停/停止以及 watchdog 故障。异常保留已同步数据并关闭模拟光源；
无法确认安全关闭或存在持久故障时不放行下一轮。

独立只读审查发现一项 Important，无 Critical/Minor：原候选峰计数遗漏了
同样高的边界峰和平台峰。新增两个策略测试和两个完整 Agent/Store 流程
测试，均先失败再修复；修复后四项及完整 87 项测试通过。没有延后的小问题。

另外补充并验证了三个运行边界：暂停待处理时先处理暂停再准备下一轮
光源；自动关光保留 watchdog 故障，只有显式 reconcile 清除；Journal
连接正常/异常退出时均关闭且异常事务回滚。最后一项会改变日志连接
生命周期，已通过原日志、Agent 及全套回归测试。

## 验证范围与观测限制

- Python 3.12.14 / Linux；不是 Windows 实机或物理仪器验收。
- 自动决策是确定性单共振峰策略；没有调用 OpenAI 或让 LLM 控制仪器。
- GitHub Actions 已配置；远端 CI 是否通过应以实际 workflow 结果为准。
- 较早在工作目录运行 TCP 时，出现过 SQLite 数据库错误及命令已派发但
  未进入 Agent 日志的情况，系统均安全中止并保留已有数据。Journal 连接
  未关闭的问题已用回归测试修复，但这些异常的全部底层原因没有被证明；
  不能据此宣称存储/传输问题已彻底解决。最终隔离临时目录的重复 TCP 验收
  和 399 点回归通过，仍建议在正式演示机器先运行自动验收。
- 旧断网验收脚本曾把重启前仍在有效期内的 online 状态当作新心跳；现改为
  等待实际带故障的心跳，再执行人工恢复。不能用缓存 online 状态替代该检查。

真实仪器接入、装置校验、硬件联锁验证及最终演示日期/名单不属于本次交付。
