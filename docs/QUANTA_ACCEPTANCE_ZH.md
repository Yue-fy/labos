## 不代表的验证

没有在 Windows 实机运行 PowerShell、Python 便携解释器或厂商 SDK；没有连接真实仪器，没有部署真实实验室 LAN/VPN/TLS。模型调用仍用 mock 验证，没有调用收费模型。软件停光读回不是独立物理急停，也不能证明样品无损伤。资格检查仅为当前光学模拟流程的运行有效性检查，不代表精度、稳态或科学机理已确认。
