# 真实仪器接入准备

本交付只包含 `SimulatedInstrument`；`mode: real` 会被 schema 拒绝，不能通过改一个配置字段将模拟代码当作真实驱动。

用户后续提供 PC 和仪器信息后，为每个型号实现受审查的 `InstrumentDriver`：`execute`、`status`、`safe_shutdown`。批准列表只允许确定的高层能力，不能暴露 shell、任意 Python 或 raw SCPI 给 AI。

## 每套装置所需信息

1. PC 名称、Windows 版本、64/32 位、当前仪器软件及是否必须在交互桌面运行。
2. 仪器制造商、完整型号、序列号、固件；USB/串口/LAN 等连接方式。
3. SDK/编程手册、SDK 支持的 Python/位数、厂商示例和现有可用脚本。
4. 实际物理连接、转台上的元件、角度与偏振关系、快门/联锁、样品约束和校准。
5. 允许范围、变化速率、稳定条件、超时、断线/重启时的安全状态，以及哪些操作不能重试。
6. 现有软件是否独占设备；实验期间谁可以操作、如何避免双重控制。

不需要提前知道所有实验室设备。先完成一套装置，保存 SetupProfile；换样或改变参数时沿用，换接线或设备时更新配置。

## 接入验证顺序

查找已维护厂商/QCoDeS/PyMeasure 驱动 → 编写薄适配层 → 模拟协议与异常 → 只读身份/状态验证 → 经操作者批准的小范围写入 → 本地中止/断线验证 → 仪器和装置登记。

便携 Agent 当前内置 Python 3.14.8 x64，仅验证模拟依赖。若厂商 SDK 需要 Python 3.11、32 位环境、.NET 或特定 DLL，应制作对应型号专用运行时，不能直接替换 DLL 后宣称兼容。

“安全关闭”不是对所有设备断电。真实适配应遵循该型号和装置的已验证动作序列；限速、联锁与样品相关约束需要具体定义。PC 掉电、硬件故障或被强制结束进程时，本地 Python watchdog 不能代替硬件保护。

原始数据轴是检测波长 `spectrum_axis_nm`，扫描轴是激发波长 `wavelength_nm`；不要混淆为同一个量。若需要能量轴或实际偏振角，应保留原始轴和转换/校准版本。
